# ArtFlow deep audit, October 2026

This audit reviewed the app across ten areas: product and parity, brush engine, canvas GL and
input, layers and undo, selection and transforms, colour, import and export security, persistence
and recovery, UI and accessibility, and performance with test coverage. It records what was fixed,
how each fix was checked, and what remains open.

It is not a parity claim. [PROCREATE_PARITY.md](PROCREATE_PARITY.md) sets the acceptance gates, and
those gates need artist and physical-device evidence that this environment cannot produce.

## Method and limits

- **No Android SDK or device** was available in the audit environment. Android code was reviewed by
  reading it. Only the Android-free packages (`core/`, `domain/`) were compiled and tested locally,
  with the Kotlin 2.0.21 compiler from the Gradle distribution and JUnit 4.
- Each fix has a regression test. For the selection, brush preset, binary-plist budget and grayscale
  PSD fixes, the test was also run against the previous code and failed there, as expected. The
  colour, glTF and Procreate tile changes were not run against the previous code.
- The full build and the device matrix run only in CI. A `workflow_dispatch` run on the branch
  verifies Android compilation, lint, device tests and the artifact checks; its result is in the
  Actions history rather than this document.
- Procreate's handbook was not reachable from the audit environment, so Procreate-side comparisons
  come from memory and are marked as such.

## Open findings, highest impact first

Severity follows the audit: P0 means data loss, wrong pixels, a crash, or exploitable input; P1
means clearly wrong or missing core behaviour. "Android" means the fix needs CI or a device.

### P0

1. **Recovery failure can delete the only snapshot** (`CanvasViewModel.kt`, `CanvasRepositoryImpl.kt`).
   A failed autosave recovery leaves the editor in Ready, and the next Save deletes the snapshot.
   Fix: keep recovery blocking until resolved, and gate save on it. Android, medium.
2. **Painting on a text layer erases it silently** (`CanvasRepositoryImpl.kt:973-988`). Editing the
   text replaces the raster and clears strokes. Fix: block paint on text layers, or rasterise first.
   Android, small.
3. **The colour-profile control relabels without converting pixels** (`CanvasRepositoryImpl.kt:1935`).
   Switching a canvas to Display P3 changes how stored values display, so colours shift. Fix:
   convert every layer inside one undoable step, or relabel as "Assign profile". Android, medium.
4. **The eyedropper and brush mix colour spaces** (`ArtFlowCanvasView.kt:2500`). Picking #FF8000 on
   a P3 canvas paints (255,119,0). Fix: convert at the picker and paint boundaries. Android, medium.
5. **USDC section counts allocate before their payload is checked** (`UsdReader.kt:341-355`). The
   binary property list and glTF cases are fixed above. Compressed sections legitimately expand
   beyond the file size, so the bound must be format-aware. Pure Kotlin, medium.
6. **Memory during preview and filters.** `separableConvolve` allocates twelve full-canvas float
   planes per call (`ImageFilters.kt:369-416`), which runs on every composite for Gaussian and
   feathered layers. Pure Kotlin, medium.
7. **CI can pass with its real-file checks skipped.** The Procreate sample fetch is
   `continue-on-error`, and the tests assume rather than fail when samples are missing
   (`android-ci.yml:71`, `RealProcreateFilesTest.kt`). Fix: fail the job when samples are absent.
   CI, small, but it can break the pipeline if the fetch is flaky, so it needs a decision.

### P1

8. **Palm rejection and touch-hold eyedropper change the brush colour** (`PointerGestureRouter.kt`,
   `ArtFlowCanvasView.kt:1752`). A resting finger or palm after the pen lifts starts a stroke, and a
   still touch of 500 ms changes the colour. Fix: latch a stylus-lift window and ignore finger
   contacts for about 1.5 s; gate the hold on finger-sized contact. Pure router logic plus Android, small.
9. **Empty or non-null selections in adjustments and transforms** (`LiveAdjustments.kt:63`,
   `LayerTransform.kt`). Partly fixed for clipboard and transform split; adjustments still treat an
   empty selection as the whole layer. Pure Kotlin, small.
10. **Alpha lock is ignored by blur adjustments and Fill Layer** (`ImageFilters.kt:384`,
    `SelectionClipboard.fill`). Pure Kotlin, small.
11. **Fill anti-aliasing paints fill colour over ink edges** (`FillTool.kt:193-213`). The edge ring
    is a dilation with alpha proportional to neighbour count, not coverage. Fix: derive coverage
    from colour distance. Pure Kotlin, medium.
12. **Brush round tips have no anti-aliasing** (`Stamping.kt`, `StrokeRasterizer.kt`). At default
    flow every edge is hard. Fix: a one-pixel ramp to the radius. Pure Kotlin, small.
13. **Brush spacing uses nominal size**, so tapers and light pressure bead (`StrokeRasterizer.kt:371`).
    Pure Kotlin, medium.
14. **Velocity uses processing time, not event time** (`Stroke.kt:18`, `CanvasRepositoryImpl.kt:584`),
    so batched samples share a millisecond. Pure Kotlin, small for the engine part.
15. **PSD 16-bit import decodes wrong, and ZIP-compressed PSD content imports as transparent**
    (`PsdCodec.kt:625-730`). Pure Kotlin, medium. Needs `Deflater`-built fixtures.
16. **Procreate `.procreate` tiles and ABR tips have no decompression budget** (`ProcreateImport.kt:34`,
    `AbrReader.kt:42-60`). Pure Kotlin for ABR, small.
17. **Autosave can be cancelled and loses up to one interval of work.** The background flush is not
    awaited or protected from cancellation (`CanvasScreen.kt:391`, `CanvasViewModel.kt:1222`), and
    each autosave rewrites every layer raster. Android, medium.
18. **Merging a pass-through group header orphans its members** (`CanvasRepositoryImpl.kt:1067-1081`).
    Android, small.
19. **Group masks are accepted but never applied** (`CanvasRepositoryImpl.kt:1517-1539`). Android, small.
20. **Canvas crop, rotate and resize silently drop editable text** (`CanvasRepositoryImpl.kt:1873-1880`).
    Android, medium.
21. **Undo does not restore the selection** (`CanvasRepositoryImpl.kt:2751`). Android, small.
22. **Stroke commits copy a full layer on the UI thread** (`CanvasRepositoryImpl.kt:682`, `:773`, `:796`).
    Android, medium.
23. **Liquify live preview is off at the audit size** (`ArtFlowCanvasView.kt:2895`), and the
    displacement pass runs on the UI thread. Android, medium.
24. **Stale blur jobs run to completion** after the preview is cancelled (`LiveAdjustments.kt`,
    `ImageFilters.kt`). Pure Kotlin, small, using per-row cancellation checks.
25. **Per-pixel boxing in blend modes** (`BlendModes.kt:48`, `:382`). Pure Kotlin, small to medium.
26. **Accessibility:** unlabelled sliders and switches, colour-only tool selection, and sub-48 dp
    targets on core controls. Compose, medium. Needs TalkBack on a device.
27. **About 660 hard-coded UI strings**, with 17 of 18 `strings.xml` entries unused and no
    translations. Large.

### Lower priority

This list is not exhaustive. Lower-priority items include the GIF transparency matte and frame timing,
the USDA nesting depth bound, flood-fill seed rounding, the gap-closing edge at the canvas border, the
emboss kernel offset, the CMYK picker's naive conversion, GPL and hex palette ordering, and several
Compose polish items.

## What is strong

- Copy-on-write undo with identity-checked commits, and one undo entry per committed stroke.
- Atomic writes with fsync and content-addressed rasters; fail-closed decoding on import.
- Premultiplied resampling and blending; separable selection feather checked against brute force.
- The pointer router state machine, tested by pointer id.
- The LZ4, LZO, PackBits and ABR decoders, which bounds-check every read.
- The sRGB transfer curve, P3 and sRGB matrices, and the HSV maths, which were exact over all colours.
