`ProcreateColorProfileDeviceTest.nativeP3DocumentKeepsItsChannelsBackgroundAndProfileThroughDiskReopen`,
at line 94: `assertNotNull(saved.checksum)` after `storage.loadDocument(601)`.

original persisted signature, clears `checksum` on the editable model, then performs any migration.
`ProjectStorage.loadDocument` returns that verified model. All preceding native P3 channel, source
profile, background and save-result assertions passed. The failed assertion therefore inspected
the wrong representation. The later PNG ICC/color, fresh-reopen and final evidence-writing steps in
that case were not reached and must not be represented as passed. Its two final P3 files are absent.

independently hashes that exact representation with only the checksum value replaced by `null`,
asserts that the decoded model's checksum is cleared, and checks that loading did not rewrite the
file. It repeats raw-signature verification after reopening and saving. All original downstream
color, ICC, background, fresh-repository and PNG byte-stability assertions remain. The identity is
unchanged. This correction requires its own completed exact-source run; it does not turn run 309 green.
