## Transform: modal Done / Cancel with numeric entry (audit: every drag commits as its own undo step, no Done/Cancel)
Procreate's Transform is modal: the layer (or selection) floats with a bounding box; modes Freeform / Uniform / Distort / Warp; a Snapping and Magnetics toggle pair; a bottom bar with Flip Horizontal, Flip Vertical, Rotate 45 degrees, Fit to Screen, Reset, and Interpolation (Nearest Neighbour / Bilinear / Bicubic); tapping the Transform tool again (or any other tool) commits; Undo while transforming steps back through the gestures of this session and the whole session is ONE entry in the layer history.
Implement:
1. A transform *session*: begin on tool select / paste; accumulate the quad/mesh in memory; show Done and Cancel (Cancel restores the original pixels exactly); a single undo step for the session; switching tools or opening panels commits (or asks nothing: commit) as Procreate does.
2. Flip H/V, Rotate 45, Fit to Screen, Reset buttons; interpolation picker incl. a **Bicubic** (Catmull-Rom / Mitchell) resampler in core/pixels (TransformQuad.kt / WarpMesh.kt render path), tested against known images (identity, 90 degree rotation exactness, flat colours stay flat, no ringing overshoot beyond 0..255 clamp).
3. **Numeric entry and pivot**: a small panel with X, Y (position), W, H or Scale %, Rotation degrees (and shear optional); typing applies exactly; a draggable pivot point for rotate/scale (default centre; snaps to centre/corners/edges). Core math in a pure class (tested): composing translate/scale/rotate about a pivot into the quad.
4. **Warp**: Procreate's Warp has Grid (a configurable mesh, e.g. 2x2 .. 8x8, drag points) and Advanced Mesh; today it is a single 4x4 Bezier patch (core/pixels/WarpMesh.kt). Add a grid-density control (at least 3x3, 4x4, 6x6, 8x8) keeping old behaviour at 4x4; points draggable with the existing machinery.
5. **Paste auto-enters Transform**: after Paste (ClipboardController.paste) the new layer is in a transform session with Uniform mode, as in Procreate.
6. Multi-layer transform keeps working (picked layers). Do not break the existing Snapping & Magnetics behaviour.
