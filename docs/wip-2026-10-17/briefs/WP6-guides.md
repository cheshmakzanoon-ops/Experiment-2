Read scratchpad/COMMON_BRIEF.md first, then scratchpad/audits/colour-guides-anim-text.md (DRAWING GUIDE section). Package name for resource files: `guides`.

## Goal (Procreate 5.x Drawing Guide, from memory): Actions > Canvas > Drawing Guide > Edit Drawing Guide
Procreate shows the guide full-screen with a bottom bar: guide type tabs **2D Grid, Isometric, Perspective, Symmetry**, sliders for **Opacity, Thickness, Grid Size**, a **colour** swatch row (guide colour), **Assisted Drawing** toggle (strokes snap to the guide), and **Done**. On the canvas you edit the guide directly: drag the grid origin/handles, drag vanishing points and the horizon, tap to add a perspective point (up to 3), drag symmetry axes, resize the grid by pinching.
Implement:
1. **Edit Drawing Guide mode**: a dedicated overlay/bar (new composable files) with Done/Reset; pointer handling for guide handles routed from ArtFlowCanvasView in a minimal hook (e.g. an `GuideEditor` interface the view delegates to while the mode is on), with 48dp hit targets, handles drawn at the VPs/horizon/axis ends/grid origin.
2. **Style**: guide colour, opacity, thickness for all guide types (replace the hard-coded colours/hairline in EditorChrome); grid size slider that really controls the spacing (today the presets are two fixed sizes and `gridSpacing` is bound to no slider); isometric angle/size; symmetry line colour.
3. **Perspective**: draggable vanishing points + horizon, add/remove points (1, 2 or 3 point), ray density, showHorizon + VP.enabled exposed, snap = lock to the ray family nearest the stroke start (a stroke locked to one ray, like Procreate's Assisted Drawing) rather than per-sample pull, with a test for the pure snapping math.
4. **Fix mismatches** (audit): grid and isometric snap lattices differ from the drawn lines unless the canvas size fits (snap uses round(x/spacing), the lines are drawn from (w/2)%spacing): make snap and drawing share one lattice definition in core and test they agree; Radial symmetry ignores Axis X/Y: make the centre movable; add the rotational-symmetry toggle (mirror + rotate copies) that Procreate offers for Quadrant/Radial.
5. **Persistence**: guides are saved with the artwork (.artflow via data/local/ProjectStorage; additive, defaults when absent; old files load unchanged; round-trip + old-file tests) and restored on reopen; the on/off prefs remain. Procreate also lets a layer be a Drawing Assist layer (exists: keep).
6. Undo/redo of guide edits is not required; Reset returns to defaults.
