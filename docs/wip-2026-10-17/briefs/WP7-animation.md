## Goal (Procreate 5.x Animation Assist, from memory)
Animation Assist shows a bottom **timeline** of frame thumbnails (each frame = a layer or group), with the current frame highlighted, a play/pause button, Settings (loop mode, frame rate, onion skin frames and opacity, onion-skin colours), +Add frame, per-frame hold (frame duration), duplicate/delete by tapping the selected frame, drag to reorder, and **Background / Foreground** layers (non-animated layers shown behind/in front of every frame). Scrubbing the timeline changes the visible frame.
ArtFlow's model is "every frame owns a full layer stack" (keep it; do not rewrite the document model). Close the UX gap on top of it:
1. **Timeline strip** (new composable file): a horizontally scrolling LazyRow of frame thumbnails at the bottom of the canvas while Animation Assist is on, tap = select frame, drag along the strip = scrub, long-press-drag = reorder, selected frame shows duplicate/delete/hold actions, a "+" tile; thumbnails render off the UI thread via a controller with an LRU cache keyed by frame revision (look at PageThumbnailController for the existing pattern) and update after edits.
2. **Playback controls**: play/pause, step previous/next, jump first/last, current frame / total readout, FPS and per-frame hold respected; **Loop | Ping-Pong | One Shot** as a single 3-way control (today two switches, both off = one-shot), plus the playbackRangeStart/End fields if cheap (set range from a selected span).
3. **Onion skin**: frames before/after (0-5 each exists) and opacity; add the **tint colours** (Procreate lets you choose colours for past and future frames; AnimationFrame has unused fields): implement in BOTH render paths (GL renderer and any CPU/export path that shows onion skin) and make the onion-skin settings **per artwork** (persisted in the document, additive format with defaults) while keeping the app-wide on/off preference as the default for new files. Test the tinting maths in core.
4. **Background / Foreground layers**: let a layer be marked Background or Foreground ("pinned": shown on every frame behind/in front, edited once). AnimationTimeline/addLayerToAllFrames hints at a prior idea: implement properly (a per-layer flag in the model; compositor shows pinned layers of the document's pinned set on all frames; export (GIF/APNG/MP4/PNG sequence) includes them; copy-on-duplicate semantics documented). Additive persistence + round-trip + old-file tests.
5. Keep export working (GIF/APNG/MP4/frames) and the existing shortcuts/caps (240 frames, 1024 layers); do not break time-lapse.
