# Release risk register

| Risk | Current treatment | Remaining evidence/work |
| --- | --- | --- |
| Saved document exceeds reopen raster budget | Consistent prospective budget is an integration requirement; limit growth before mutation | Regression plus real device persistence verification. |
| Archive heap spikes / orphan temporary files | Route gallery imports to bounded disk staging and streamed repository operations | Oversize, cancellation, damaged archive, navigation, and cleanup tests. |
| Failed package changes existing brush textures | Prevalidate metadata and all grains; reject differing existing IDs; retain ownership through Room publication | File/cache collision, failed/cancelled publication, and concurrent-adoption regressions. |
| External layered import fails after work starts | Preflight known capacity before mutations; check every imported pixel/mask/group result | Unexpected later failures may leave already imported layers; whole-import rollback remains separate work. |
| Linked operations silently affect only some members | Require complete eligible membership and transactional commit | Masks, locks, selection conflicts, undo, save/reopen, UI tests. |
| Android15 16 KB emulator ART instability | Keep independent lanes, runtime identity, full logs, and narrow one-recovery contract | First-invocation outcomes remain distinct; physical ARM64 campaign still open. |
| CPU/full-buffer painting limits | Describe actual architecture and device-dependent limits | Real pen latency, frame times, thermal/long-session/low-memory workloads. |
| Format/brush fidelity exceeds integrated scope | Document supported settings, bit depth, and appearance fallbacks | Receiving-application tests; finish metadata and curve consumers. |
| Prototype classes mistaken for completed features | Require a real editor caller and integration evidence | Separate sparse/GPU, CMYK, typography, 3D milestones. |
| Supply-chain inventory incomplete | Pinned actions, selected-pattern secret scan, direct dependency inventory | Resolved transitive dependency/license and vulnerability review. |
| Unsigned or unqualified public build | Signing guard and explicit production NO-GO | Publisher, physical device, upgrade, and store acceptance. |
